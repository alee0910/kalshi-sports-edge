About this system

This repository implements a research-only model-vs-market system for Kalshi sports event contracts. It includes: (1) domain research for MLB, NBA, NFL (v1) plus lit-review stubs for NHL, golf, tennis, soccer, CBB, MMA, NASCAR; (2) six strategy specs grounded in academic literature on sports betting market inefficiencies; (3) a fee-aware backtest engine; (4) a scanner running on GitHub Actions every 20 minutes; (5) calibration reports updated daily.

Repository layout

  • research/kalshi/ — microstructure, fees, client
  • research/domain/ — sport literature reviews
  • models/<sport>/ — pregame + in-game models
  • strategies/ — six v1 strategies + registry
  • backtest/ — engine + synthetic data + FINDINGS
  • scanner/ — live cron + candidate output
  • dashboard/ — this static site (GitHub Pages)

Disclaimer

This is not investment advice. Kalshi sports contracts are event-based derivative products regulated (as of April 2026) by the CFTC, with an active rulemaking docket and pending appeals of state-level injunctions. Nothing on this site is an offer to transact in any jurisdiction where doing so would be unlawful. Massachusetts residents specifically: the state's preliminary injunction remains in effect as of the most recent Third Circuit ruling; no orders are configured for MA jurisdictions in this system. Past performance does not predict future results.
